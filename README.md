## 📱 Responsive Design

The website is designed to provide a consistent and user-friendly experience across different screen sizes.

Responsive considerations include:

- 🖥️ Desktop
- 💻 Laptop
- 📱 Tablet
- 📱 Mobile devices

The layout adapts key elements such as navigation, hero content, service sections, portfolio cards, forms, buttons, typography, images, and footer content to different viewport sizes.
## ♿ Accessibility

Accessibility was considered throughout the development of the website to make the interface clearer and easier to navigate.

Accessibility practices include:

- Semantic HTML5 elements
- Logical heading hierarchy
- Descriptive `alt` text for meaningful images
- Appropriate `aria-label` attributes
- Appropriate `aria-labelledby` attributes
- Keyboard-friendly navigation
- Clearly identifiable interactive elements
- Structured and readable page content
- Accessible navigation landmarks
## 🔎 SEO & Performance

The website includes technical foundations designed to support search visibility, usability, and performance.

SEO and performance considerations include:

- XML sitemap
- Robots.txt configuration
- Web App Manifest
- Descriptive image `alt` attributes
- Optimized WebP image assets
- Responsive layouts
